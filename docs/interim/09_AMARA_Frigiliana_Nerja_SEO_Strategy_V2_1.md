1. Strategic role
This document translates search-demand observations into AMARA's current Type A/B/C/D architecture. It is
a working strategy, not a technical or URL authority.
All implementation must still follow AMARA System V4, Core V4, Runtime/SEO V4, and URL/Route V4.

2. Core thesis
The strongest AMARA search opportunity is not "Frigiliana accommodation" in isolation.
The real decision space is the Frigiliana-Nerja stay corridor:
- authentic village stay;
- coast and beach access;
- countryside calm;
- practical movement and parking;
- accommodation-type fit;
- quiet versus convenience.
Guests are often solving a trade-off rather than searching for a single destination name.
AMARA should therefore own stay-decision clarity, not generic tourism volume.

3. Confirmed strategic observations
The following remain useful working conclusions from the earlier research set:
- Nerja is the stronger broad search anchor.
- Frigiliana often carries more qualitative, atmosphere-led intent.
- "Near Nerja but quiet", countryside/coast combinations, parking, pool, views, and practical access
  represent high-value decision modifiers.
- Comparison and modifier-led searches are more aligned with AMARA's authority than broad OTA-
  dominated head terms.
- Multilingual search behavior differs enough that copy must be localized by market, not translated literally.
These are directional strategy inputs, not guarantees of ranking or volume.

4. What guests are optimizing for
Guests are choosing a stay model, not only a property.
Common decision variables include:
- village character;
- beach spontaneity;
- quiet;
- parking and driving friction;
- walkability;


- pool;
- views;
- family practicality;
- romantic fit;
- longer-stay functionality;
- self-catering suitability.
AMARA content should translate these variables into clear trade-offs and next steps.

5. Architecture mapping
Type A - Location Authority
Best-fit strategic jobs:
- where to stay in the Frigiliana-Nerja corridor;
- Frigiliana versus Nerja;
- parking/driving reality;
- village versus coast versus countryside;
- which base fits which traveler type;
- practical access and movement questions.

Type B - Explore
Best-fit jobs:
- how Frigiliana feels to stay in;
- quiet village evenings versus coastal energy;
- countryside mood and rhythm;
- experiential contrasts after practical fit is understood.

Type C - Trust
Best-fit jobs:
- direct-booking confidence;
- guest reviews;
- host accountability;
- comfort/service standards;
- booking/stay FAQs.
Trust should not own location comparison.

Type D - Conversion
Best-fit jobs:
- specific AMARA stay selection;
- availability and booking;
- fit-based accommodation collections;
- property sale/investment conversion where relevant.
Conversion pages should connect clarified demand to actual inventory rather than create unsupported
category pages.

7. Multilingual architecture and evidence-led emphasis
The core decision architecture remains stable across English, German, Spanish, Dutch, and Swedish.

Localization may change wording, native query vocabulary, examples, FAQ emphasis, link labels, and section
depth when evidence supports the difference. It must not create five different page jobs or information
architectures.

Evidence rule
Do not infer content order from nationality stereotypes such as "German = parking", "Swedish = winter sun", or
"Dutch = self-catering". Language, nationality, and travel behavior are separate variables.

Market-specific emphasis should be supported by real search behavior, Search Console data, booking
evidence, or another appropriate source. Until such evidence exists, use the shared decision architecture and
native-language editorial judgment.

Cross-language SSOT
 • physical and operational facts remain shared;
 • page type and decision job remain shared;
 • claim boundaries and proof requirements remain shared;
 • sentences, idiom, examples, headings, and query phrasing are localized independently.

This model supports native search language without allowing speculative market psychology to fragment the
system.


8. High-value query classes
Continue to prioritize four classes of intent:

8.1 Bridge intent
Examples conceptually include village/coast/countryside combinations and "near Nerja but quieter" trade-offs.
These searches are valuable because the user is already resolving a stay decision.

8.2 Direct comparison
Examples include Frigiliana versus Nerja or village versus beach stay models.
These align strongly with AMARA's authority role.

8.3 Modifier-led commercial intent
Examples include parking, pool, sea view, quiet, romantic, family, or long-stay suitability.
Only build a dedicated conversion surface when real AMARA inventory can satisfy the modifier honestly.

8.4 Native accommodation language
Use market-native terminology in titles/headings/copy where it reflects actual search and inventory
semantics.
Do not translate slugs.

9. Internal linking strategy
Authority is the routing layer for uncertainty reduction.
Recommended flow:
- broader Authority -> focused Authority comparison/logistics;
- Authority -> Explore when emotional fit helps after structure is clear;
- Authority/Explore -> Trust when confidence becomes the barrier;
- Authority/Trust -> Conversion when the user has enough clarity to choose a stay;
- Conversion -> relevant Authority/Trust only when an unresolved objection remains.
Do not create spoke-to-spoke link density merely for SEO. Links should match the next decision.

10. What not to do
Do not:
- chase generic OTA-style head terms as the primary strategy;
- publish thin keyword variants;
- translate slugs;
- create conversion categories the inventory cannot support;
- mix parking/logistics into Explore pages;
- mix comparison into Trust pages;
- add new pages when an existing page already owns the job;
- use AI-generated keyword ideas as evidence of demand without validation.

12. Overnight Location Authority Model
12.1 Overnight-first principle
Frigiliana location authority is written primarily for prospective overnight guests, not day visitors. Search
demand generated by day-trip behavior must not automatically be interpreted as an overnight-stay pain point.

The relevant question is not only what Frigiliana is like to visit, but how it functions as a place to live for
several consecutive days.

12.2 Micro-location principle
"Frigiliana" is not sufficiently precise as an accommodation-location description. The stay experience
changes materially between upper historic Barribarto, the historic Calle Real / Iglesia / Chorruelo axis, the
lower or modern village, and countryside or outer hillside locations.

Topography, repeated walking routes, vehicle access, and spontaneous village participation must therefore
be interpreted at micro-location level.

12.3 AMARA Frigiliana position
AMARA's Calle Chorruelo location sits within the historic village while remaining comparatively low within the
historic topography. This is a real practical advantage for some stay models because it combines historic-
village immersion and strong walkability with lower repeated vertical friction than many higher Barribarto
locations.

This must not be presented as a unique, best, or friction-free location without comparative evidence.
Frigiliana remains a hillside village.

12.4 Mobility and parking model
The preferred working model is:

   village life on foot -> Nerja / coast / region by bus or car

A car is not a requirement for staying in Frigiliana. It is, however, a meaningful flexibility advantage for airport
arrival, Maro, larger shopping trips, multiple beaches, and wider regional exploration.

For a straightforward Nerja or beach day, public transport may be sufficient where current schedules support
it.

Overnight guests experience a different parking rhythm from day visitors. AMARA first-party hosting
experience indicates that later-afternoon and evening parking is generally more relaxed than the daytime
visitor peak, but this is not a guarantee of immediate parking availability.

Exact hourly release-window claims must not be published as general facts without measured evidence.


12. Overnight Location Authority Model - continued
12.5 Frigiliana + Nerja stay model
Frigiliana and Nerja should be treated as complementary stay environments rather than forced into a winner-
versus-loser framework.

Frigiliana is particularly strong when the guest wants the historic village to function as home while using
Nerja, beaches, and the wider region as daytime options. When immediate beach walkability and coastal
spontaneity dominate the stay decision, Nerja may be the better AMARA base.

12.6 Behavioral segmentation
Location content should segment by travel priorities and desired stay behavior, not by nationality stereotypes.
Language editions may differ in wording, query vocabulary, examples, FAQ emphasis, and content depth
where evidence supports it.

12.7 Authority-to-conversion principle
AMARA may be integrated directly into Type A location authority when its actual property location, operating
experience, or accommodation facts materially help answer the location question.

The preferred editorial pattern is:

   Place -> Overnight consequence -> AMARA fit or limitation -> Verifiable proof -> Guest decision ->
   Natural next step

Not every place fact requires an AMARA mention. Not every AMARA relationship must be framed as an
advantage. A limitation or a recommendation of another AMARA location may be the correct answer.

12.8 First-party Location Intelligence
Where commercially valuable claims depend on local physical reality, AMARA should prefer first-party
measurement over additional generic tourism research. Priority evidence may include real walking routes,
distances, elevation, steps, parking observations, daily-living routes, and coded verified guest feedback.

These measurements support content quality but do not alter route, resolver, schema, or page-type
architecture.

14. Working hypotheses versus confirmed decisions
Confirmed system decisions
- stay-decision architecture is central;
- authority precedes Explore expansion;
- page intent must remain pure;
- slugs remain language-neutral and frozen;
- localization happens in copy, not URLs;
- direct booking is a separate infrastructure path;
- current existing pages should be reused before new pages are created.

Working hypotheses requiring future evidence
- exact search volume of bridge terms;
- which modifier-led landing page would produce the highest incremental bookings;
- which language deserves the next content-investment priority;
- whether corridor-level wording should receive a dedicated new public page beyond the existing
  hub/comparison system;
- which top-funnel route yields the strongest progression to accommodation pages.

15. Readiness gate for new SEO pages
Before approving a new public page:
- identify a real user decision that is not already owned;
- classify A/B/C/D;
- prove non-overlap with existing pages;
- confirm parent and next-step links;
- confirm inventory/factual support;
- confirm canonical slug and token plan;
- define language-market emphasis;
- define how success will be evaluated.
If the new page does not reduce a distinct uncertainty or capture a distinct valid conversion intent, do not
create it.

16. Strategic takeaway
AMARA's advantage is not content volume. It is the ability to explain the trade-off between village character,
countryside calm, coast access, practical movement, trust, and real accommodation fit.
The strategy should therefore continue to build structured decision support around real stays, while
resisting generic tourism expansion and unsupported conversion categories.
