# Frigiliana Connection Map — compact pilot

Date: 2026-08-28  
Scope: Frigiliana Location, Experience and Casa AMARA projections  
Status: working map before public authoring

## 1. Working rule

This is a **menu, not a fixed itinerary**. Guests may combine weather, hiking, beaches, food, village time and private retreat in different orders.

A connection is approved only when:

1. the source page contains the relevant statement;
2. that statement creates a real next guest question;
3. the target owner answers that question with its own full narrative;
4. any Casa AMARA consequence uses verified property or operator evidence;
5. a reciprocal connection adds value and does not duplicate the source narrative.

A bare link, generic related-content list or repeated page copy is not a connection.

## 3. Connections needing only a focused live check

| Connection | Existing premise | Small missing check | Result after closure |
|---|---|---|---|
| Weather ↔ Hiking | The regional seasonal contrast and four canonical route profiles are evaluated | Name the official forecast/warning source and define route-specific current-condition wording | Weather explains seasonal suitability; Hiking translates the actual forecast into route and timing choices and returns to Weather for the live layer |

Exact Frigiliana monthly climatology, ERA5 extraction and property-level microclimate precision are **not prerequisites** for either connection.

## 4. Connections needing a short operator evidence note

| Connection | Required note — no broad research run | Why it matters |
|---|---|---|
| Hiking ↔ Casa AMARA | One dated door-to-official-start and return log per selected route: actual path, duration range, steps/surface, uncertainty and the genuinely used return routine | Makes Casa AMARA part of the hiking day without falsely calling it the trailhead |
| Hiking ↔ Restaurants | One genuinely tested route-finish/meal combination: date, route, venue, realistic timing, transport or walk and current-operation check | Turns “hungry after hiking” into a usable host recommendation |
| Restaurants ↔ Sundowner / return | One genuinely tested combination: meal, onward place or Casa AMARA return, date, parking/walk and timing | Creates the user’s desired personal continuation instead of a nightlife list |
| Daily Life / supermarkets ↔ cooking at AMARA | First-arrival and top-up shopping route, with/without car, plus a per-unit kitchen capability matrix | Supports the choice between eating out and cooking privately without dumping inventory into the supermarket narrative |

Personal host language may use only real AMARA observations. External research can support facts and context, but it cannot be rewritten as a first-person experience.
